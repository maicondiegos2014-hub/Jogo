# Jogo Mario

## Descrição

Jogo inspirado no Mario, desenvolvido como projeto acadêmico utilizando tecnologias de desenvolvimento web. O jogador controla o personagem Mario, que deve pular os obstáculos. Ao colidir com um obstáculo, o jogo é encerrado e um efeito sonoro de game over é reproduzido.
Jogo do Mario desenvolvido com HTML, CSS e Java Script.

## Objetivo

O objetivo do projeto é aplicar conhecimentos de HTML, CSS e JavaScript no desenvolvimento de um jogo, além de utilizar Git e GitHub para controle de versão, organização e desenvolvimento colaborativo.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Instalação

O projeto utiliza HTML, CSS e JavaScript puro, portanto não é necessária a instalação de dependências.
